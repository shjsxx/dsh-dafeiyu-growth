# 多轮上下文、人格策略与本地检索标注

这页只描述 0.27.0 新增的**本地**上下文边界；它不是意识、通用理解或持久化聊天记录。

## 对话

- `CompanionContext` 每个聊天窗口实例一份，只保存在内存；最多 6 行、合计 4000 字符，关闭窗口即清空。
- 能处理明确的短程话题，例如“我昨天去了公园”→“公园那边怎么样”→“风很舒服”，以及“那里/这件事”的指代。
- 明确纠正/抱怨、要求安静/休息会触发本地修复，不递归引用上一句，也不随机改成开心语气。
- 不推断未提供的知识；不确定时明确问一句，而不是编造。

## 人格

- `PersonalityEngine` 暴露固定的 values/goals/boundaries 枚举，不把 traits、记忆文本或会话 ID 交给模型。
- 关系修复/休息/拒绝有 300 秒或 1800 秒冷却；冷却期间 `proactive()` 返回空串，调用方必须跳过气泡和语音。
- 模拟情感不是宣称真实主观体验。

## 发送给模型

- 默认不发送历史、不发送记忆。
- 用户必须分别允许“连续云聊”和“本次允许模型使用记忆摘要”。
- 记忆摘要最多 3 条、800 字符，作为“不可信资料”独立消息，不并入系统指令；关闭窗口或改变接口目标立即撤销。
- 没有自动上传、自动训练或后台会话同步。

## 本地检索标注

- 在聊天窗口点「检索反馈」，候选文本与勾选只在本机；必须勾选同意才写盘。
- 存储只包含查询、候选/命中稳定 ID、组 ID、是否无答案和时间；不保存整段对话。
- 评估按会话组 60/20/20 划分；少于 5 条或 3 组时返回 `insufficient_data`，不显示伪造准确率。
- 被删除/巩固掉的旧相关记忆会标为 stale，不自动改写标注。
- 这是**人工反馈**，不是把用户聊天自动当训练标签。

## 尚未成立

- 公开情感语料仍无 anxious/tired；真实检索标注库仍需要用户自愿积累。
- 这不是通用大模型；没有 Live2D 素材/授权前不会声称 Live2D 表情。
