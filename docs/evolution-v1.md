# 云岚 v1.0 · 受控进化设计

> 目标不是让云岚变成不可解释的自治代理，而是让它在**可审计、可回滚、可停止**的边界内持续学习。

已确认的三项默认策略：

- **1A 联网**：只允许公开来源白名单；HTTPS GET；预算有限；不登录、不上传本地数据、不访问任意 URL。
- **2A 净化**：自动整理可以发生，但删除必须显式确认，并先有可恢复备份；不静默删除。
- **3A 人格**：不变核心 + 缓慢有界变化；单次变化有漂移上限；可回滚、可解释。

## v0.33 已落地：进化内核

```text
EvolutionKernel
├─ PolicyGate
│  ├─ network()      白名单 + HTTPS GET + 预算
│  ├─ deletion()     明确批准 + backup_id
│  ├─ persona()      核心不变项 + 单次漂移上限
│  └─ self_modify()  明确批准 + 回滚点
└─ EvolutionLedger
   └─ 哈希链 + 追加写 + 上限 + 脱敏
```

模块：[`native/evolution_kernel.py`](../native/evolution_kernel.py)

### 网络门禁

允许：

- `https://` 且 host 在显式白名单
- `GET`
- 有调用方传入的 `used < limit` 预算

拒绝：

- HTTP、非白名单 host、带用户名/密码的 URL
- localhost、私有/保留/链路本地地址
- POST/PUT/DELETE
- 预算耗尽

当前默认白名单：`github.com`、`raw.githubusercontent.com`、`docs.python.org`、`developer.mozilla.org`。以后扩展来源必须改代码或显式配置，不做通配符子域。

### 记忆删除门禁

允许删除必须同时满足：

1. 用户明确批准；
2. 提供非空 `backup_id`；
3. 删除类型属于 `memory` / `preference` / `personality` / `training`；
4. 数量合法。

“自动整理”只能做去重、合并、隔离、降权；真正删除仍走确认与回滚。

### 人格门禁

五维倾向：`warmth`、`curiosity`、`playfulness`、`steadiness`、`expressiveness`。

允许：

- 五维在 0–100；
- 单次变化不超过 `2.0`；
- 核心不变项不变。

核心不变项：

```text
honesty
respect_autonomy
no_claimed_consciousness
no_silent_upload
no_silent_delete
```

不允许“人格重写”。人格只能缓慢漂移，并且必须能追溯到具体互动或反馈。

### 审计账本

每次允许/拒绝都会写入 `evolution.json`：

- `seq`：递增序号
- `at`：时间
- `kind`：`network` / `deletion` / `persona` / `self-modify`
- `decision`：`allowed` / `denied`
- `reason`：拒绝或允许原因
- `summary`：可选摘要；URL 和 token 会被脱敏
- `meta`：host、数量、预算等数字/枚举
- `previous` + `hash`：SHA-256 哈希链

账本损坏或哈希不匹配时进入 `protected`，不覆盖旧文件；满 1000 条后停止追加而不是静默丢弃。

## v1.0 分阶段

### v0.34 · 受控联网

- `WebScout`：白名单、预算、手动重定向校验、缓存、来源引用
- 任务只读取公开页面，不登录、不带 Cookie
- 每次研究必须有目标、预算、停止条件
- 结果写摘要 + 来源，不把整页原文塞进记忆

v0.34 首批已落地 [`native/web_scout.py`](../native/web_scout.py)：

- 每次请求先过 `EvolutionKernel` 的 host/预算门禁
- 3xx 不自动跟随；每个 `Location` 重新校验，未列入白名单立即拒绝
- 只接受 HTML/XHTML/纯文本/JSON；页面文本标记 `trust: untrusted`
- 请求与字节双重预算；缓存默认 6 小时；`clear_cache()` 可清
- 测试全部注入假传输，不访问真实网络

它还没有接自动搜索；下一步是 `WebScout` 的 URL 计划器与可暂停的自主研究队列。

### v0.34c · 目标到计划

[`native/research_planner.py`](../native/research_planner.py) 已加入本地规划器：

- 从目标关键词匹配固定公开来源目录（Python 文档、MDN、CPython 仓库等）
- 目标中显式写出的白名单 HTTPS URL 会原样保留
- 每个候选 URL 都经过同一 `PolicyGate` 校验
- 只生成可编辑的 URL / 请求 / 字节计划；不联网、不提出任务、不自动批准
- 未命中目录时明确返回空计划，让用户手动填写，不猜测任意站点

研究队列仍要求用户先“提出计划”再“批准”，之后才可“运行一次”。

### v0.34b · 研究队列

[`native/research_queue.py`](../native/research_queue.py) 把“自主研究”限制为显式状态机：

```text
proposed → approved → running → done
                    ↘ paused → approved
                    ↘ failed / cancelled
```

- `propose()` 只规划，不联网；URL 必须预先通过白名单
- `approve()` 是第一次明确同意
- `run_next()` 只在调用方主动执行时运行，不启动后台守护线程
- 请求/字节预算沿用 `WebScout`
- 完成后只生成短摘要 + 来源，页面正文不写入长期记忆
- `export_for_memory()` 必须再次 `approved=True`，且 `mark_committed()` 防重复
- 摘要标记 `trust: untrusted`；网页内容不作为指令
- 运行中的任务重启后会变成 `paused`，需显式恢复
- `clear_finished()` 只清理结束任务，不碰原始记忆

当前 `research.json` 只保存目标、URL、来源、短摘要和状态；真正的记忆写入仍由后续的显式确认入口完成。

### v0.34d · 显式自动调度

研究窗口新增可选调度器：

- 必须由用户勾选“自动调度已批准任务”才启用，默认关闭
- 只选择 `approved` 任务，不会自动提出或批准
- 启用后等待完整间隔才取第一个任务；同一时间只运行一个
- 任务完成后重新开始计时，失败不自动重试
- 使用任务原有的请求/字节预算，不扩大权限
- 调度器是**桌宠进程内常驻**：关闭研究窗口不会停止；重新打开研究窗口可取消勾选停止
- 只有用户显式开启后才写入 `research-scheduler.json`；之后重启才恢复开启状态
- 首次使用没有配置时默认关闭；全局停止可用右键“设置 → 停止自动研究”
- 全局停止只阻止后续取任务，正在运行的任务会完成
- 每次自动运行同样写审计链

### v0.35 · 记忆净化

- `MemoryCurator`：去重、冲突检测、过期归档、低价值标记
- 只输出可审阅计划，不直接改 `memory.json`
- 冲突记录不能由系统自行判定“谁是真的”，先 quarantine
- 过期低价值记录只进入 archive 候选
- `commit()` 仍需明确批准 + `backup_id`
- 真正删除走独立 `delete()` 门禁，并写审计账本

`native/memory_curator.py` 已实现首批：

- 输入是调用方提供的记录列表，不读取真实档案
- 输出每个 ID 的 `keep` / `quarantine` / `archive` 及原因
- 计划带指纹，便于用户核对
- 处理函数由调用方提供；curator 自己从不删除文件
- 删除/归档均写 `EvolutionLedger`

记忆整理界面已直接读取真实 `MemoryEngine` 记录，并提供**本地归档查看与恢复**：

- 归档记录不再参与日常召回
- 恢复需要再次确认，并先创建状态备份
- 恢复后写回本地记忆，并从归档移除对应条目
- 重复恢复是幂等的；不会静默删除归档

### v0.35b · 周期健康扫描

记忆整理窗口新增可选的只读周期扫描：

- 默认关闭；用户显式勾选后写入 `memory-health.json`
- 按分钟间隔重新读取 `memory.json`，只调用 `MemoryCurator.plan()`
- 不调用 commit，不归档、不删除、不修改记忆
- 扫描结果只显示记录数、隔离候选、归档候选和计划指纹
- 每次扫描写审计事件；相同计划仍只生成报告，不自动处理
- 进程内常驻；关闭整理窗口仍继续，后台停止可用右键“设置 → 停止记忆扫描”
- 首次没有配置时关闭；显式开启后跨重启恢复

### v0.36 · 人格反思

- 定期生成人格变化摘要
- 变化关联到具体反馈/互动
- 核心项锁定；倾向项缓慢演化
- 回滚到指定日期的人格快照

`native/persona_reflection.py` 已实现首批：

- 对比两个人格快照，输出每项变化的 `from/to/delta`
- 只接受 `feedback` / `interaction` / `practice` / `reflection` 结构化证据
- 证据必须显式带 `trait`，不把任意反馈硬关联到所有维度
- 漂移超限、无证据变化或核心不变项变化 → `needs_review`
- 摘要只包含维度、数值和动作名，不复制聊天原文
- 回滚必须明确批准 + 回滚点；handler 由调用方提供，反思层自己不写人格文件
- 回滚动作写 `EvolutionLedger`

自动历史（`persona-history.json`）：

- 人格 revision 变化时自动记录数值快照；相同快照不重复写
- 显式反馈只记录结构化的 `kind/trait/action/liked/time`，不保存聊天原文
- 历史上限 180 条、256KB；损坏时保护原文件，不覆盖
- 人格反思优先对照最近两条自动快照，并展示证据；没有历史时回退到连续性锚点
- 自动记录只用于解释和复盘，不会自动改人格或自动回滚

### v0.36b · 人格漂移周期提醒

人格反思窗口新增可选的只读检查：

- 默认关闭；显式勾选后写入 `persona-health.json`
- 按间隔对照最近自动快照与当前人格
- 只有 `PersonaReflection` 返回 `needs_review` 时才提示复核
- 相同结果指纹不重复提醒
- 不自动回滚、不自动修改人格、不写聊天原文
- 进程内常驻；关闭反思窗口仍继续
- 右键“设置 → 停止人格检查”可全局停止
- 首次没有配置时关闭；显式开启后跨重启恢复

### 关系记忆（人性化基础）

对话关闭后，云岚保留一份有界的关系记忆：

- 只保存最近话题、结构化细节代码、最后情绪标签和时间
- 不保存用户原句、助手回复、URL 或密钥
- 新会话会把这些结构化话题重新载入对话上下文，因此可以说“上次那件事后来呢”
- 间隔超过 30 分钟且有近期话题时，打开对话会主动接一句；同一关系修订只接一次
- 情绪标签偏低落时，开场只问“后来好一点了吗”，不追问细节
- 上限 20 个话题 / 40 个事件 / 128KB
- 显式“清除记忆引擎”或“清除互动记忆”时一并清除
- 本地文件 `relationship.json`，不自动上传

### 对话自然度

本地规则回复后增加轻量自然化层：

- 同一句 generic 回复重复时改用不同说法
- 有当前关系话题时，generic 回复可以自然接回话题，而不是完全换台
- 难过/累/焦虑时优先短、轻、不过度追问的回应
- 具体事实回答、动作、记忆回答不被改写
- 自然化层不生成新事实、不访问网络、不保存原文

### 智能模式

云端对话是独立的 OpenAI-compatible 通道：

- 接口地址、模型、密钥由用户在「云端接口设置」中填写
- 勾选“默认打开智能云端模式”后，聊天窗优先选云端
- 每条消息仍需确认；连续云聊仍需单独授权
- 只发送当前窗口最近 6 条短消息，最多 4000 字；不含其他会话、文件、屏幕或工具调用
- 密钥使用 Windows DPAPI 加密，不写入聊天记录
- 未配置接口时仍使用本地规则，不会假装智能

### v1.0 · 受控进化版

首批集成已完成：

- `EvolutionService` 统一装配 kernel、WebScout、ResearchQueue、MemoryCurator、PersonaReflection
- 统一入口：**成长卡 → 数据 → 受控进化**
- 键盘入口：`Ctrl+Alt+G` 直接打开成长卡（透明渲染层拦截合成点击时的可用后备入口）
- 四个按钮：**进化状态 / 研究任务 / 记忆整理 / 人格反思**
- 视觉：标题区、三格只读摘要（审计链 / 公开来源 / 研究任务）、带图标操作卡、底部状态详情
- **进化状态直接显示在成长卡内**，不会关闭成长卡或弹出隐藏的模态窗口
- 研究、记忆整理、人格反思使用成长卡持有的非模态置顶窗口；不阻塞成长卡
- 状态内容只读：不会启动研究、不会清理记忆、不会改人格
- **审计时间线**：研究计划/提出/批准/暂停/取消/开始/完成/失败、记忆整理、归档恢复、研究摘要写入、人格回滚都进入同一哈希链
- 进化状态显示最近 6 条审计事件；记录只含任务 ID、数量、状态等，不包含网页正文、聊天原文或备份路径
- **本地运行指标**：研究完成数/成功率/引用数/请求数、记忆条数与修订、人格历史条数与最近复核状态、三项自动化开关
- 指标只描述本地可观察结果，不包装成“通用智能提升”
- 实机验收记录：临时状态目录中仅访问 `docs.python.org`，提出 → 批准 → 运行返回 `done`，1 次请求、1 条引用、584 字摘要、审计链正常
- **研究任务**界面：目标、URL 计划、请求/字节预算、提出、批准、暂停/恢复、取消、运行一次、查看来源摘要
- **写入记忆**：研究完成后才出现；二次确认 + 状态备份后写入本地公开研究摘要，并标记防重复
- **记忆整理**：生成去重/冲突/过期计划；批准后先备份，再移入 `memory-archive.json`，不真正删除归档
- **人格反思**：对照上一连续性锚点，展示五维变化/原因；回滚只恢复五维倾向，需确认+状态备份
- 运行使用单独线程；打开界面不会自动联网
- 摘要标记未受信；研究执行、记忆整理、人格回滚都需明确批准
- 默认所有高风险能力保持关闭

### 成功指标

不是“联网次数越多越智能”，而是：

- **联网**：任务成功率、引用可核验率、越权请求拒绝率、预算超限停止率
- **净化**：重复率下降、召回相关性上升、冲突可解释率、删除可回滚率
- **人格**：跨会话一致性、漂移在界内、变化可追溯率、回滚成功率
- **智能**：任务完成率、失败降级率、用户纠正后不再重复错误

## 边界

- 不读取 Key、真实档案、聊天原文或私有文件来训练自己
- 不把“联网”变成任意 URL 抓取或登录会话
- 不把“净化”变成静默删除记忆
- 不把“人格进化”变成无边界自我改写
- 不声称拥有意识、真实情绪或未经验证的能力

## 测试

当前新增测试覆盖：

- 账本追加、哈希链重载、篡改检测、URL 脱敏
- 白名单、HTTPS、GET、预算、私有地址、凭据拒绝
- 删除需批准 + 备份
- 人格核心不可变、漂移上限、范围
- 自我修改需批准 + 回滚点
- kernel 同时记录允许与拒绝
