# 0.28.0 · 云岚 Web 成长手记

本次重做的是 **DSH 设置 → 内置插件 → 云岚养成**，不是原生桌宠的七页成长窗口。现有原生 helper、模型、存储格式及成长计算规则均不变。

## 信息架构

- **成长概览**：等级与阶段、真实升级进度、五阶段路线、连续天数/对话/工具调用、四维属性、习惯线索和最新回顾。
- **成长回顾**：按全部/阶段成长/日常回顾筛选本地最近 20 条记录。
- **数据与隐私**：详细计数、档案时间、隐私范围说明、统计摘要导出、独立的清零确认区。

设计采用低饱和岚青色、清晰标题、统一卡片间距和原创云朵矢量装饰。样式只作用于 `.ylg` 根元素；使用容器查询适应窄设置栏，提供宽屏双列、深浅色及减少动态效果规则。阶段与数字仍来自原来的本地数据接口，没有虚构趋势或展示用统计数字。

属性说明直接对应现有公式：体力来自有效会话时长，灵性来自工具与项目多样性，亲和来自对话/审批互动，定力来自已结束对话的成功占比。这是统计映射，不是心理测量、通用模型训练或真实能力评分。

## 网络、并发和操作安全

- 首次加载后，每轮请求完成才安排下一次轮询，默认间隔 15 秒；不叠加请求。
- 页面隐藏暂停普通轮询；恢复时再读取。已明确提交的清零不因页面隐藏而被重复提交。
- 请求有超时、取消与版本隔离；卸载会清理轮询、监听器和请求，旧响应不能覆盖清零后的新状态。
- 读取失败保留上次成功数据并提示陈旧；没有成功数据时显示错误/重试，而非用示例数字填充。
- 清零必须展开确认并准确输入「清零」，只有 HTTP 成功、`ok: true` 和有效的新 state 才显示成功。
- 清零超时不声称档案原封不动，也不自动重试；提醒先刷新核对。已有服务器备份/提交回滚逻辑保持不变。
- 档案健康异常会提示并禁用清零；不会把后端可能含本机路径的原始错误直接展示。
- 取消、Escape、完成清零后，在 React 提交完 UI 更新后恢复键盘焦点。

## 隐私范围

摘要导出使用明确白名单，仅有版本、经验、等级/阶段、连续天数、计数、四维属性和创建/更新时间；**不含项目名/ID、工具名、习惯原文、回顾、会话或任何任意后端扩展字段**。导出由浏览器下载到本机，不上传。下载请求不等于浏览器已落盘，界面文案要求在下载列表核对。

本页清零只处理成长档案，**不是**清除原生桌宠聊天、语音、记忆或所有 DSH 会话。页面已明确区分这些范围。没有变更云端、麦克风或记忆授权，测试不接触真实成长档案。
